# ✨ Maria Rogéria Cosméticos — Vitrine Digital & Gestão de Ofertas

Catálogo web Mobile-First desenvolvido para divulgação diária de promoções (Natura, O Boticário, Mary Kay) em grupos de WhatsApp, com conversão direta para atendimento e painel administrativo otimizado para uso via smartphone.

## 🛠️ Stack Tecnológica
* **Backend:** Python 3 + Flask (Arquitetura em Camadas / POO)
* **Banco de Dados & Storage:** Supabase (PostgreSQL + Bucket público para imagens)
* **Frontend:** HTML5, CSS3, Bootstrap 5 (Mobile-First)
* **Hospedagem:** Vercel (Serverless)
